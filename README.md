# Good Drivers Unite

Good Drivers Unite is a Framework7 application packaged with Apache Cordova for
Android and iOS. The web application source lives in `www/`; the Cordova
project configuration and native resources live in `cordova/`.

## Prerequisites

- Node.js and npm
- Apache Cordova CLI
- Android Studio and an Android SDK for Android builds
- Xcode and CocoaPods for iOS builds (macOS only)

Install JavaScript dependencies from the repository root:

```bash
npm install
cd cordova
npm install
cd ..
```

## Development

Run the web version locally:

```bash
npm start
```

The development server opens at `http://localhost:8080`.

## Cordova Builds

The build script copies the contents of `www/` into the generated
`cordova/www/` directory and injects the Cordova runtime script. Build commands
must be run from the repository root:

```bash
npm run build-cordova
npm run build-cordova-android
npm run build-cordova-ios
```

Do not edit `cordova/www/`, `cordova/platforms/`, or `cordova/plugins/` by hand.
These directories are generated by the build and are excluded from Git.

## Project Layout

| Path | Purpose |
| --- | --- |
| `www/` | Main web application source |
| `cordova/` | Cordova configuration, native resources, and plugins |
| `build/` | Scripts that prepare the Cordova web bundle |
| `assets-src/` | Source icons and splash-screen assets |

## Configuration

The Parse application configuration is currently defined in `www/js/app.js`.
Keep server credentials, signing keys, keystores, and local environment files
out of the repository. Replace the placeholder Android background-geolocation
license in `cordova/config.xml` with a valid local or release configuration
before producing a release build.
